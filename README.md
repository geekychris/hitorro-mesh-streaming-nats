# Hitorro Mesh Streaming Nats

NATS JetStream LocalTable adapter for Hitorro Mesh agents — subscribes a durable JetStream consumer as a streaming partition, exposes JVS messages with event-time watermarks so the mesh can run SQL-over-streams queries against live NATS topics.
